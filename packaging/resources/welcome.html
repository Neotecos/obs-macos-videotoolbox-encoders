Apple VideoToolbox RealTime Encoders for OBS Studio

This installer adds two Apple VideoToolbox RealTime hardware encoders to OBS Studio:

  • Apple VT H264 Hardware Encoder (RealTime)
  • Apple VT HEVC Hardware Encoder (RealTime)

The Tools menu includes an option to use these encoders for Multitrack Video.

Currently compatible services: Twitch Enhanced Broadcasting, Amazon IVS Multitrack Video, and Dolby OptiView Real-time Enhanced Broadcasting (Dolby Millicast in older OBS versions).

The plugin is installed for the macOS user currently logged in. Restart OBS Studio after installation.

Requires macOS 13 or newer, Apple Silicon, and OBS Studio 31.1.0 or newer.
